## Встановлення та запуск
1. Встановити залежності:
   ```bash
   pip install -r requirements.txt
2. Підключити конфігурацію mcp.json у клієнті LM Studio (розділ Connected Apps).

3. Запустити будь-яку модель із підтримкою Function Calling (наприклад, Qwen2.5 7B Instruct).
